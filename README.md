# Programação Imperativa e Funcional (PIF)

## 📖 Sobre o Projeto

* **Objetivo:** Registro e versionamento das atividades práticas e listas de exercícios da disciplina de Programação Imperativa e Funcional (PIF).
* **Escopo:** Soluções em Linguagem C, contemplando desde a estrutura e sintaxe fundamental até a resolução de problemas computacionais.
* **Foco:** Desenvolvimento com boas práticas de programação, modularidade e controle de versão.

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagem de Programação:** C
* **Compilador:** GCC (MinGW-w64)
* **Ambiente de Desenvolvimento:** Visual Studio Code (VS Code)
* **Controle de Versão:** Git / GitHub

---

## 📋 Diretrizes de Entrega

* **Organização Própria:** As atividades são divididas por pastas correspondentes a cada lista enviada.
* **Modularidade de Código:** Cada questão prática possui um arquivo `.c` individual e independente.
* **Documentação Teórica:** Respostas teóricas são formalizadas em formato Markdown (`respostas.md`).
* **Padrão e Rigor:** Código estruturado seguindo as boas práticas da Linguagem C e com devida documentação interna.
